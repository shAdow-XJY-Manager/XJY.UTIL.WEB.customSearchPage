# 极简新标签页

网站与 Chrome／Microsoft Edge 扩展共用的原生网页。主页面保留搜索框、可编辑快捷链接和右上角设置入口；使用系统字体，默认纯色背景，不包含字体包、内置壁纸、Flutter 或 WASM 运行资源。

## 运行与构建

需要 Node.js 22.12+ 和系统 `zip` 命令。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
npm run build
npm test
npm run check:size

# 单独构建网站或扩展
npm run build -- web
npm run build -- extension

# 网站部署到根目录或其他子路径
npm run build -- web --base-href=/
```

- 网站产物：`build/web/`，默认部署路径 `/XJY.UTIL.WEB.customSearchPage/`。
- 扩展目录：`build/extension/`。
- 扩展 ZIP：`build/releases/frequency-search-1.4.0.zip`，版本以 `package.json` 为准。
- 体积报告：`build/releases/size-report.json`。构建强制 ZIP ≤200 KiB、解压资源 ≤400 KiB，并拒绝字体、WASM、Flutter 资源和权限白名单之外的能力。
- 当前版本压缩包约 165 KiB，解压资源约 315 KiB；开发工具和旧 Flutter 源码均不进入交付包。
- 已有 Dart 环境仍可使用 `dart run tool/build.dart [all|web|extension] [--base-href=/path/]`，该入口转交 Node 构建。

`native/` 是当前运行实现，`lib/`、旧 `web/` 和 Dart 测试保留作历史参考。生产构建不使用 Flutter SDK。现有 Pages 发布可将网站产物复制到 `docs/`，保留 `.nojekyll`；本轮不会自动覆盖或发布 `docs/`。

## 安装与更新扩展

1. 解压 ZIP 到长期保留的目录，或直接使用 `build/extension/`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展」，选中含 `manifest.json` 的目录。
4. 点击「＋」或按 `⌘T`（Windows/Linux 为 `Ctrl+T`）。若浏览器询问是否保留新标签页变更，选择保留。

更新时覆盖同一目录，并到扩展管理页点击「重新加载」；已经打开的页面也需刷新。不要先卸载或移动目录，以保留扩展 ID 和本地设置。

停用后新标签恢复浏览器默认页，数据仍保留；卸载会移除扩展数据。多个新标签页扩展可能相互覆盖。本项目面向桌面普通窗口，无痕窗口不接管新标签页。

## 搜索与设置

- 点击搜索框中的引擎图标，查找 35 项内置搜索入口，包括网页、知识与技术、视频社区和购物；也可切换自定义引擎。菜单支持方向键、Enter、Escape；切换保留输入内容并返回输入焦点。
- 设置 → 搜索 → 自定义搜索引擎，可添加／编辑／删除名称与包含 `%s` 或 `{query}` 的搜索网址。删除当前自定义项后回到 Bing。目录与官方来源见 [SEARCH_ENGINES.md](SEARCH_ENGINES.md)。
- Enter 或右侧搜索按钮提交。中文输入法组合期间的 Enter 不会提前搜索；页面首次打开不抢占地址栏焦点。
- 扩展默认在当前标签打开结果，网站默认另开标签，保存过的选择优先。
- 设置入口打开浮动面板，按「外观／搜索／快捷链接」分页；外观页集中展示背景预览、主题与布局；语言入口位于标题栏地球图标，与设置标题和关闭按钮同排。主题默认跟随系统并实时响应系统变化，也支持浅色、深色覆盖；自定义颜色在折叠区。
- 图片主题默认开启：沿原图边缘延展空间颜色，模糊扩散并随距离渐隐到系统底色；浅色和深色分别控制衰减，原图不受影响。自定义页面颜色优先；可在外观设置关闭图片取色。
- 设置按钮根据所在区域的实际背景自适应图标与底衬，包含图片适配、留白、遮罩和自定义颜色；图片无法取色时使用系统主题回退。
- 设置面板底部的 GitHub 图标在新标签打开仓库；“重置”按钮有明确边框。保存成功不显示常驻提示，失败仍显示错误。
- 新选择的本地图片按原始文件保存：不缩小尺寸、不转换格式、不重新编码，保留透明度、元数据和动画。已移除应用内原有的文件大小／像素限制和缓存读取大小限制；实际可用范围由浏览器解码能力与本机存储空间决定。存储空间不足时提示原因并保留原背景。旧版已压缩的缓存无法还原，需重新选择原文件。
- 图片适配与遮罩仅作用于图片背景。「恢复纯色」只移除图片；「重置」重置偏好、快捷链接和自定义引擎，保留已经完成的一次性导入标记。
- 保存失败时会在设置中提示。图片保存失败保留原背景；存储不可用时只在当前页面临时生效。

## 多语言

设置标题栏 → 地球图标，默认跟随 `navigator.languages` 的首个支持语言；手动选择优先，保存在本机。恢复默认会回到跟随浏览器。未支持的浏览器语言回退到英文。

内置 16 种：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语、印尼语、土耳其语、越南语。语言选择器使用各语言原名。支持 `zh-Hans`／`zh-Hant`、港澳台、新加坡及常见地区后缀匹配。

界面、对话框、提示、错误、无障碍标签、引擎分类和页面标题一同切换；不翻译用户的查询、自定义名称、网址或文件名。阿拉伯语采用 RTL：面板与设置入口移到左侧，快捷链接保持可见，搜索输入按内容方向显示，网址字段保持 LTR。

翻译在 `native/locales/`，统一入口为 `native/i18n.js`，不使用在线翻译服务或字体下载。141 条基础文案均有完整的 16 语言版本，测试核对数量与占位符。新增语言需补齐语言表并通过 `npm test`。这是一版完整界面译文，尚未进行逐语种母语人工审校。

扩展的名称／描述通过标准 `_locales` 元数据本地化，构建自动生成；葡萄牙语同时生成 `pt_BR` 和 `pt_PT` 入口，共用葡萄牙语文案。构建后仍检查原有体积上限。

## 快捷链接

搜索框下方按行显示本机保存的快捷链接。点击添加按钮可新增名称与网站地址；悬停时点击右上角菜单，或右键链接，可编辑、删除、前移或后移。拖动可排序，聚焦链接后按 Alt + 方向键也可调整顺序。正常点击在当前标签打开；Ctrl／⌘ 点击沿用浏览器行为。设置中可隐藏整组链接。

扩展设置提供「导入浏览器常用网站」：点击后请求可选 `topSites` 权限，读取完成立即撤回该权限。最多读取 24 项，与现有链接去重合并；成功提交链接与标记后不再读取。拒绝授权、读取失败、存储失败或没有可导入的新项时可重试。数据只写本项目的 IndexedDB，不修改浏览器数据。主题、背景、布局和快捷链接分字段原子保存，避免其他标签页的无关修改覆盖刚导入的数据；切回页面时刷新已保存状态。

[Chrome 官方接口](https://developer.chrome.com/docs/extensions/reference/api/topSites)明确不包含用户手动固定的原生快捷链接，因此这里导入的是常用网站。网站版不支持浏览器数据读取，可手动添加。

快捷链接图标：扩展仅常驻 `favicon` 权限，用浏览器本机缓存；缺失时显示通用图标。网站版快捷链接使用本地通用图标，不向第三方图标服务发送用户网址。按 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/how-to/ui/favicons)，浏览器可能为 `favicon` 显示权限提示。没有 `history`、`tabs`、书签或主机访问权限。

## 自由布局

在设置中选择「编辑布局」：

- 拖动搜索框移动位置；拖四条边或四个角调整宽高。
- 框体获得焦点后，方向键移动；缩放手柄获得焦点后，方向键调整对应边缘。Shift 每次调整 10px，普通方向键每次 1px。
- 「重置」只重置本次布局草稿；「取消」或 Escape 恢复进入编辑前的布局；「完成」统一保存。
- 快捷链接随搜索框排列；底部空间不足时临时夹取搜索框显示范围，链接超过三行时可滚动，不改写保存尺寸。
- 编辑时暂停搜索框和快捷链接交互，退出后隐藏手柄及工具条。
- 默认 600×56px，水平居中，中心位于页面高度的 42%。最小尺寸随字号适配，并限制在可用视口内。
- 窗口变窄时临时限制显示范围，恢复较大窗口时恢复保存尺寸，不覆盖原布局。

## 本地数据与旧版兼容

使用原生 IndexedDB 数据库 `frequency_search_v2`，数据库版本 2、状态格式 3。1.2.0 的数字引擎选择转换为稳定标识；背景、颜色、布局和已保存主题不重置。升级与 `upgrade-backup` 中的 1.2.0 快照一起提交。旧页面连接在升级时关闭，防止旧代码覆盖新字段；更新后请刷新已有标签页。1.2.0 不能读取升级后的原生数据库，回退代码前须从备份恢复到独立的版本 1 数据库副本验证，不能直接清空数据。

首次启动只读导入同一来源的旧 `shadow._db` 数据，包括引擎、搜索打开方式、本地图片、遮罩、适配、颜色和布局。

迁移结果和完成标记一起提交。迁移读取失败不标记成功，重新加载可重试；恢复默认保留完成标记，避免旧设置再次出现。旧数据库不改写，旧版仍可读取自己的数据；新版修改只写新库。

网站、扩展、不同浏览器分别保存数据，没有账号同步、设置导入／导出、统计或上传。照片保存在浏览器存储中，不增加安装包体积；搜索时关键词发送给所选引擎。扩展页面和本地背景可离线使用，实际搜索需要网络。

## 验证

```sh
npm test
npm run build
npm run check:size

# 可选：安装浏览器集成检查，需项目内或全局安装 Playwright
node tool/verify_browser.cjs chrome
node tool/verify_browser.cjs edge
node tool/verify_web.cjs
```

集成脚本默认使用 macOS 应用路径，其他系统可用 `BROWSER_EXECUTABLE` 指定可执行文件。使用独立临时配置，结束后删除测试配置；截图和结果保留在 `build/qa-native-chrome/`、`build/qa-native-edge/`。DevTools 加载仅作用于当前会话，重启检查会重新加载同一路径并核对磁盘数据。

界面图标使用 Fluent UI System Icons 的实际 SVG 子集，许可证及固定版本来源随产物放在 `licenses/`。搜索引擎与扩展 PNG 复用本项目已有资源。

取色使用浏览器本地 [Canvas 像素读取](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/getImageData)，不上传图片，也不增加扩展权限或字体资源。详细验证范围见 `VALIDATION.md`。

## 搜索图标与环境光

35 个内置引擎均包含轻量本地图标，首次离线也完整显示。24 个 Simple Icons 图标使用固定版本 jsDelivr 链接按需读取，成功后保存在本机 Cache Storage，后续优先读缓存；下载失败、断网或缓存写入失败时继续使用包内图标。其余来自原项目、官网 favicon 和 Font Awesome。许可证、归属及来源见 `native/licenses/` 和 `native/engine-icon-sources.json`。这不是搜索服务官方背书。

仅请求预先列出的公开品牌图标，不上传搜索词、图片、快捷链接、自定义引擎网址。CSP 仅额外允许连接 `https://cdn.jsdelivr.net`，没有新增主机权限、远程脚本或字体。环境光只读取本地图片的低分辨率颜色样本；原始文件保存和显示不变，无持续动画循环。

设置 → 快捷链接 → “显示添加按钮”可单独隐藏主页添加入口，已有链接仍显示，设置中的添加功能始终可用。
